# 产品路线图

> 日期：2026-06-07  
> 状态：早期路线图

## Phase 0: 文档内核

目标：

```text
把 AI 商业实验室的判断、原则、流程和实验模板固化下来。
```

已完成：

- 项目原则
- 项目级技能
- 初始商业实验
- 高考后本地消费实验
- 运行记录和内核升级记录

## Phase 1: 可展示项目

目标：

```text
让项目能被人快速理解。
```

交付：

- 中文 README
- 项目结构说明
- 服务端运行时说明
- 静态展示页
- 当前实验展示

## Phase 2: 最小服务端

目标：

```text
让项目可以在服务端启动。
```

交付：

- `apps/web`：前端展示和操作台
- `apps/api`：读取项目状态的 API
- `apps/worker`：执行每日信号和实验工作流
- `runtime/scheduler`：定时任务配置
- `data`：结构化数据
- `deploy`：部署说明

## Phase 3: 半自动商业实验

目标：

```text
每天自动产生候选机会，但外部动作仍需人工批准。
```

交付：

- 每日信号雷达
- 候选机会池
- 实验设计生成
- 反馈和转化记录
- 人工批准队列

## Phase 4: 收入验证

目标：

```text
验证项目是否真的能产生现金流。
```

指标：

- 第一笔 499/999 元收入
- 可复用交付模板
- 至少一次真实客户反馈
- 至少一次复盘升级

## Phase 5: 产品化

目标：

```text
从服务型实验升级为可复制产品。
```

可能方向：

- 本地商家热点营销助手
- 小团队商业机会雷达
- 垂直行业 AI 商业情报系统
- Agent 驱动的商业实验室 SaaS
