# Workflows

本目录用于固化 AI 商业实验室每天、每周、每个实验周期如何运行。

## 目标工作流

```text
daily-radar
→ opportunity-expansion
→ experiment-design
→ validation
→ retrospective
```

## 当前兼容说明

当前工作流散落在：

- `methods/`
- `skills/`
- `experiments/*/`
- `runs/`

后续新增可执行工作流时，应优先放入本目录。

## 约束

工作流只能自动执行低风险内部动作。

外部动作必须等待用户批准：

- 发布
- 私信
- 联系商家
- 收款
- 承诺收益
