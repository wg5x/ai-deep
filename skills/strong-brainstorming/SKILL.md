# Strong Brainstorming

## Core Rule

Do not stop at the literal seed.

First expand far, then return to business reality.

## Divergence Modes

For any seed, generate associations across:

| Mode | Examples for "blue" |
|---|---|
| Adjacent | green, purple, water, sky |
| Opposite | red, heat, warning, blood |
| Metaphor | freedom, depth, loneliness, calm |
| Scale jump | ocean, planet, universe, atmosphere |
| Emotion | trust, melancholy, distance, purity |
| Culture | uniforms, flags, brands, religion, rituals |
| Nature | ice, sea, storm, whale, night |
| Technology | screens, LEDs, interfaces, satellites |
| Commerce | packaging, identity, tourism, fashion, events |
| Risk | coldness, sadness, distance, authority |

## Flow

```text
Seed
→ literal meanings
→ adjacent associations
→ opposite associations
→ metaphor and emotion
→ scale jumps
→ cultural and commercial symbols
→ weird but useful directions
→ opportunity expansion
→ commercial selection
```

## Output Shape

```text
Seed:
Literal layer:
Near associations:
Far associations:
Opposites:
Metaphors:
Emotions:
Cultural symbols:
Commercial angles:
Strange but useful ideas:
Best directions to explore:
```

## Guardrails

- Quantity before judgment in the first pass.
- Include some surprising ideas, not only safe ideas.
- Do not confuse creativity with randomness; every far association should still be explainable.
- After divergence, use `opportunity-expansion-engine` and business filters to select.
