# Opportunity Expansion Engine

## Core Rule

When the user gives 1, expand to 10 or 100 before narrowing.

Do not only execute the literal idea. Build an opportunity surface, then select the most commercial experiments.

If the seed is abstract, metaphorical, emotional, aesthetic, or the user asks for stronger imagination, run strong brainstorming first:

```text
literal -> adjacent -> opposite -> metaphor -> emotion -> scale jump -> culture -> commerce
```

## Expansion Flow

```text
Seed
→ strong brainstorming when needed
→ 10 surfaces
→ 100 materials/questions/examples
→ opportunity clusters
→ ranked experiments
→ cash-flow offer candidates
```

## 10 Surfaces

For any seed, expand across:

1. Timeline: before, during, after, downstream
2. People: buyers, sellers, influencers, gatekeepers
3. Emotions: anxiety, pride, celebration, fear, curiosity, convenience
4. Spending: products, services, subscriptions, events, consulting
5. Channels: Xiaohongshu, Bilibili, WeChat, offline, communities
6. Local scenes: Beijing districts, stores, venues, schools, offices
7. Policy and compliance: encouragement, restrictions, platform rules
8. Open-source leverage: tools that reduce execution cost
9. AI leverage: research, content, automation, sales, delivery, review
10. Portfolio fit: small cash-flow, medium service, large venture

## Output Format

```text
Seed:
Why it matters:
10 surfaces:
Top opportunity clusters:
Materials to collect:
Small experiments:
Medium experiments:
Large experiments:
First cash-flow offer:
Risks:
Next action:
```

## Selection Rule

After expansion, select by:

```text
urgency + buyer clarity + AI leverage + channel access + compliance safety + 7-day testability
```

Never choose only the most interesting idea. Choose the idea that can teach the system fastest, especially through payment, rejection, or detailed feedback.

## Avoid

- Stopping at the user's literal example
- Creating a giant list with no ranking
- Treating attention as demand
- Ignoring local China/Beijing context
- Ignoring legal, platform, or ethical risk
