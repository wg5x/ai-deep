# 商业蓝海评分规则

> 日期：2026-06-07  
> 状态：生效草案  
> 适用范围：AI机会雷达商机筛选

## 1. 评分目的

蓝海评分不是为了制造精确数字。

它用于快速筛选：

```text
哪些机会值得继续调研？
哪些机会可以直接做小实验？
哪些机会应该暂时放弃？
```

## 2. 评分维度

每项 0-5 分。

| 维度 | 说明 |
|---|---|
| 需求强度 | 用户痛点是否真实、频繁、明确 |
| 支付可能性 | 是否存在明确付费方和预算 |
| 供给空缺 | 现有解决方案是否不足 |
| 政策顺风 | 是否符合国家/地方鼓励方向 |
| 合规可控 | 是否避开高风险领域 |
| 小团队可验证 | 是否能 7-14 天内低成本验证 |
| AI 杠杆 | AI 是否显著降低交付成本或提高质量 |
| 本地可接触性 | 在北京/中文平台是否能找到反馈对象 |
| 差异化 | 是否避免和大厂/成熟平台正面竞争 |
| 转化路径清晰度 | 是否能从内容/微信/服务化走到付费 |

最高 50 分。

## 3. 判断区间

| 分数 | 判断 | 动作 |
|---:|---|---|
| 40-50 | 高优先级蓝海候选 | 进入深度调研和小实验 |
| 30-39 | 中优先级候选 | 补证据，做轻量访谈 |
| 20-29 | 弱候选 | 暂存观察 |
| 0-19 | 不建议推进 | 放弃或等待新信号 |

## 4. 一票否决项

出现以下情况，不能进入实验：

- 明显违法违规
- 涉及虚假宣传或保证收益
- 需要高风险牌照但无法取得
- 用户数据和隐私风险不可控
- 可能误导医疗、金融、教育等高敏感人群
- 主要依靠平台灰产或绕规则套利

## 5. 输出格式

每个机会评分必须写：

```text
机会名称：
总分：
最高分维度：
最低分维度：
为什么现在：
最大风险：
本周验证动作：
继续标准：
放弃标准：
```
