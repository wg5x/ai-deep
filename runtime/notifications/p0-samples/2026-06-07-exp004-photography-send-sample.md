# P0 草案：是否向已回复商家发送一页样例

> 日期：2026-06-07
> 状态：样例草案
> 触发条件：商家已回复愿意看一页样例
> 注意：没有用户再次批准，不发送样例。

```text
【需要你确认】
事项：是否向已回复“愿意看样例”的摄影商家发送一页文字样例

为什么找你：
这是第二步外部动作。虽然商家已经表示愿意看，但发送样例仍然会影响真实外部沟通，所以必须再次确认。

发送对象：
仅发送给已经明确回复“愿意看样例”的商家。

发送方式：
建议仍由你手动复制发送。Agent 不自动发送，不使用 Hermes，不使用机器人。

我已经准备好：
1. 商家可看的一页文字样例
2. 样例发送边界
3. 样例后的 3 个反馈问题
4. 商家问价格/微信/电话/定制时的处理方式

本次只做：
发送一页文字样例，并询问对方这个方向是否有用、哪里需要改。

本次不做：
不报价
不收款
不加微信
不电话沟通
不承诺客流/成交
不索要考生信息
不使用照片或真实学生素材

建议选择：
批准由用户手动发送一页样例；如果商家问价格、定制、微信或电话，再进入下一次 P0。

超时默认动作：
不发送样例。

你可以回复：
1 批准，由我手动复制发送
2 暂停
3 给我更多信息
4 换方向
5 晚点再说
```

## 回复后的动作

| 用户回复 | Agent 下一步 |
|---:|---|
| 1 | 提供可复制样例和反馈记录格式 |
| 2 | 不发送样例，记录为暂停 |
| 3 | 补充样例、风险或替代版本 |
| 4 | 回到实验/子方向选择 |
| 5 | 记录为待恢复，不执行 |

## 发送后仍需 P0 的情况

- 商家问价格
- 商家要微信/电话
- 商家愿意提供真实门店信息
- 商家要求定制方案
- 商家询问付款方式
- 商家要求使用真实作品/照片
- 商家涉及考生、未成年人或敏感信息
