# P0 样例：是否进入高考后摄影方向触达准备

> 日期：2026-06-07
> 状态：样例
> 注意：这是 P0 通知样例，不代表已批准外部触达。

```text
【需要你确认】
事项：是否把 Experiment 004 的第一轮现金流验证聚焦到“高考后/18 岁纪念摄影写真包”

为什么找你：
这会决定接下来 48 小时我把内部准备资源投向哪个方向。它还不是外部触达，但属于方向选择。

我已经准备好：
1. 高考后本地消费营销包实验框架
2. 30 个公开候选商家池
3. 摄影/餐饮/驾校三类样例变体
4. 摄影方向 4 个优先候选
5. 触达话术草案和合规边界

建议选择：
批准进入摄影方向的内部触达准备。先完善样例和话术，不对外发送。

你可以回复：
1 批准，只做内部准备
2 暂停
3 给我更多信息
4 换方向
5 晚点再说
```

## 回复后的动作

| 用户回复 | Agent 下一步 |
|---:|---|
| 1 | 完善摄影版本样例、候选适配和下一条正式触达 P0 |
| 2 | 暂停 004，保留材料 |
| 3 | 补充对比：摄影 / 餐饮 / 驾校 |
| 4 | 重新选择主实验或子方向 |
| 5 | 记录为待恢复 |

## 重要边界

即使用户回复 `1`：

- 不私信商家
- 不发样例
- 不报价
- 不收款
- 不使用用户账号
- 不启用熟人关系

真正触达前必须再次 P0 确认。
