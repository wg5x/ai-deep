# Kernel Changelog: Run 012

> 日期：2026-06-07  
> 类型：架构修正 / 技能内核升级

## 变更

- 新增项目级 `skills/` 目录。
- 新增 4 个 AI 商业实验室 v0.1 技能。
- 新增 `AGENTS.md`，声明项目级 skills 的加载约定。
- 修正使命文档，将项目从 `AI Opportunity Radar` 上移为 `AI 商业实验室`。
- 明确 skills 必须可复制、可迁移、可版本管理，不依赖本机全局 Codex 目录。

## 新增原则

```text
技能属于项目，不属于运行环境。
运行时可以替换，技能内核必须跟随项目迁移。
```

## 自我反省

本轮一开始把 skills 写入了本机全局目录，这是错误方向。

用户指出未来运行环境会迁移到服务端，因此技能必须项目化。已撤回全局副本，并改为项目内 `skills/*/SKILL.md`。

## 后续影响

后续创建任何长期能力时，默认优先写入项目仓库。

只有在明确需要个人 Codex 全局能力时，才写入全局 skills。
