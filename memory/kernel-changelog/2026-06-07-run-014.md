## 新增原则

```text
不要把热点当作单点新闻。
要从一个点带出一个面，再从面里拆时间链、人群链、消费链和实验链。
```

## 自我反省

此前在处理高考和世界杯时，我更倾向于选择一个短期可执行实验。

这个方向有价值，但还不够前瞻。

用户指出：高考之后还有志愿填报，考前还有祈福和陪考，考后还有录取和入学准备。这个提醒说明系统必须具备“生命周期市场展开”能力，不能只追最靠近现金流的单点。

## 后续影响

未来看到任何热点，应默认先问：

```text
它的前一段是什么？
后一段是什么？
它带出了哪些人群、情绪、消费和服务？
哪些适合小实验，哪些适合中长期实验？
```
