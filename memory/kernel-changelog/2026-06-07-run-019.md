## 新增经验

```text
真实关系资源优先于陌生市场假设。
第一实验不一定要找最大市场，而要找最快拿到真实反馈的市场。
```

## 后续修正

用户随后决定不启用该私人资源。

因此上面的经验需要加一个前提：

```text
真实关系资源只有在用户愿意启用、社会成本低、失败不伤关系时才优先。
```

## 自我反省

此前我更倾向于从高考、世界杯这类公共热点切入。

用户提供书法朋友后，优先级应调整：真实资源可以缩短反馈链路，降低触达成本，更符合“借力”和“小船”原则。

这句话也需要修正：真实资源能缩短反馈链路，但不应自动覆盖用户的舒适度和关系成本。

## 后续影响

后续机会排序时，应增加一项：

```text
用户是否已有真实资源或关系入口？
```

有真实关系入口的机会，即使市场不最大，也可能更适合作为第一验证。

同时新增一项：

```text
用户是否愿意启用这个资源？不启用它是否也能推进？
```
