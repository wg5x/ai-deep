## 判断升级

后续机会排序新增一项：

```text
资源启用舒适度
```

评估问题：

- 用户是否真的愿意启用这个资源？
- 启用它是否会产生关系压力？
- 实验失败是否会伤害关系？
- 不用它是否仍然能推进验证？
- 这个资源能否复制，还是只能用一次？

## 策略调整

当私人资源不适合启用时，优先转向：

```text

可复制模板
```
