## 自我反省

此前我容易把“脑暴”理解成有结构地扩展商业机会。

这还不够。

用户要求的是更大的联想能力：从字面跳到相反、隐喻、情绪、文化、自然、宇宙，再回到商业。

## 新规则

```text
当用户给出一个抽象词、颜色、情绪、文化符号或模糊直觉时，
不能直接商业化。
必须先做强脑暴，扩大想象力边界。
```

## 后续影响

强脑暴将作为 `opportunity-expansion-engine` 的前置步骤。

商业筛选仍然保留，但不能过早介入。
