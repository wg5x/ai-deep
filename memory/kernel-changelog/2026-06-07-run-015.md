## 自我反省

此前我容易在用户指出一个方向后，迅速把它落成一个单点实验。

这种执行力有价值，但还不够像商业伙伴。

真正的主动性应是：

```text
先发散到足够大的机会森林，
再用商业标准收敛到最值得验证的现金流实验。
```

## 后续影响

未来处理任何用户种子想法时，应优先触发 `opportunity-expansion-engine`。

发散不是为了堆列表，而是为了：

- 帮用户看见没说出口的可能性
- 扩展商业想象力
- 避免过早锁定单点
- 提高命中现金流机会的概率
