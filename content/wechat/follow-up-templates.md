# WeChat Follow-Up Templates

> Status: 可使用草案  
> Channel: WeChat follow-up  
> External send: Not executed

## 1. 加微信后的第一条

```text
你好，我是「AI机会雷达」这个实验的发起人。

谢谢你愿意看样例。这个项目现在还在验证阶段，不是成熟产品。

我想测试的是：把AI新闻拆成可验证的商业机会，这件事对创业者/产品/顾问到底有没有用。

我先发你样例，你有空看完后，直接说哪里有用、哪里没用就行。
```

## 2. 发样例时

```text
这是样例简报：

[这里放样例内容或链接]

你看的时候可以重点帮我判断5件事：

1. 这是不是你的真实需求？
2. 它像不像普通AI资讯？
3. 哪个机会方向最有价值？
4. 你会不会想每周看？
5. 如果是围绕你的领域定制，你会不会考虑付费？
```

## 3. 轻量催反馈

```text
不急，等你方便的时候看就行。

我最想听的是负反馈：哪里没用、哪里太虚、哪里不像商业机会。
这些反馈比夸我更有价值。
```

## 4. 对方表示感兴趣

```text
太好了。

我现在还在验证阶段，所以想继续问一个更直接的问题：

如果这份简报改成围绕你的行业/项目方向定制，你会愿意付费试一次吗？

不用客气，直接说真实想法就行。
```

## 5. 对方说像普通资讯

```text
这个反馈很关键，谢谢。

那我想追问一下：如果要让它不像普通资讯，你觉得它必须多提供什么？

比如：
- 更具体的产品方向
- 更明确的目标用户
- 竞品/替代方案
- 验证动作
- 成本和变现路径
```

## 6. 对方说暂时不需要

```text
明白，这也很有帮助。

我想确认一下：是你本身没有这个需求，还是这个形式没有打中你？

如果未来它变成某个更具体的版本，比如“AI副业机会雷达”或“AI企业服务机会雷达”，你会更感兴趣吗？
```
