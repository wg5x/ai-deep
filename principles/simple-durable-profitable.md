# 简单、持久、挣钱原则

> 日期：2026-06-07  
> 状态：生效  
> 适用范围：AI 商业实验室 / 所有机会筛选和产品设计

## 1. 三个目标

本项目必须长期围绕三个词：

```text
简单
持久
挣钱
```

任何方案如果无法解释这三个词，都不能进入优先级。

## 2. 简单

简单不是低级，而是可启动、可交付、可复盘。

判断问题：

- 7 天内能不能做出第一版？
- 需要用户做的事是否很少？
- 交付物是否清楚？
- 能否不用先做复杂系统？
- 失败后能否快速知道错在哪？

## 3. 持久

持久不是一开始就做大，而是每次实验都沉淀能力。

判断问题：

- 这个机会是否能复用为模板？
- 是否能积累客户、素材、流程或数据？
- 是否能从一次热点延伸到长期需求？
- 是否能从服务变成产品？
- 是否能让 Agent 的判断更强？

## 4. 挣钱

挣钱不是喊口号，而是看证据。

证据等级：

| 等级 | 证据 |
|---|---|
| 0 | 只有想法 |
| 1 | 有人点赞/收藏 |
| 2 | 有人评论/私信 |
| 3 | 有人愿意聊具体场景 |
| 4 | 有人愿意试用或提供资料 |
| 5 | 有人付第一笔钱 |
| 6 | 有人复购或转介绍 |

## 5. 一票否决

以下情况默认降级或停止：

- 需要大量前期投入但没有买家证据
- 需要强合规资质但无法控制风险
- 只能靠夸大收益获客
- 只能做一次，无法沉淀
- 交付过重，AI 无法显著降低成本
- 用户喜欢听，但没人愿意付钱

## 6. 项目口号

```text
轻启动，真验证，能复用，能收钱。
```
