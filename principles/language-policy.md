# 项目语言规范

> 日期：2026-06-07  
> 状态：生效  
> 适用范围：AI机会雷达 / Autonomous Venture Loop 项目所有后续文档与内容

## 1. 默认语言

本项目后续默认使用中文。

适用范围包括：

- 策略文档
- 运行日志
- 商业实验
- 运营内容
- 小红书/B站/微信内容
- 调研报告
- 复盘备忘录
- 内核升级提案
- 任务计划

## 2. 允许保留英文的场景

以下场景可以保留英文：

- 代码、命令、文件名、接口字段
- 英文产品名、公司名、论文名、协议名
- 外部英文资料标题
- 必须引用的英文原文短句
- 面向海外市场的内容草案
- 双语对照时的英文版本

## 3. 写作风格

中文文档应尽量：

- 直接
- 可执行
- 少空话
- 少抽象名词堆叠
- 保留关键判断
- 明确下一步动作

优先使用：

```text
结论 → 理由 → 证据 → 动作
```

## 4. 历史英文文档处理

已有英文文档不立即全部重写。

迁移原则：

- 正在使用的文档优先中文化
- 面向运营/发布/用户的文档优先中文化
- 仅作为历史记录的英文文档可以暂时保留
- 若英文文档继续作为内核规范使用，应补中文版本或中文摘要

## 5. 未来规则

从 Run 008 之后：

```text
新增项目文档默认中文。
英文只在必要处保留。
```
