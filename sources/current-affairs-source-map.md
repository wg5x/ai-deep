# 时政新闻信息源地图

> 日期：2026-06-07  
> 状态：生效草案  
> 适用范围：AI机会雷达中国市场宏观风向监测

## 1. 官方与权威源

| 来源 | 用途 | 频率 |
|---|---|---|
| 中国政府网 | 国务院政策、会议、政策解读 | 每周 |
| 新华网 | 国家级时政、外交、产业要闻 | 每周 |
| 人民网/人民日报 | 中央叙事、产业方向、理论文章 | 每周 |
| 央视新闻 | 重大时政、新闻联播口径、社会关注 | 每周 |
| 国家网信办 | AI、数据、算法、内容治理 | 每周 |
| 工信部 | AI+制造、产业数字化、机器人、算力 | 每周 |
| 文旅部 | AI+文旅、消费、场景建设 | 每周 |
| 北京市政府/首都之窗 | 北京本地政策和场景 | 每周 |

## 2. 商业辅助源

| 来源 | 用途 |
|---|---|
| 财新、36氪、晚点、钛媒体等 | 商业解释和公司动态 |
| 产业公众号 | 行业落地反馈 |
| 小红书/B站/知乎 | 用户表达和社会情绪 |
| 招投标/政府采购平台 | 真实预算和需求 |
| 招聘网站 | 企业实际在补什么能力 |

## 3. 每条新闻的可信度规则

优先级：

```text
官方原文 > 新华/人民日报/央视 > 部委/地方官网 > 严肃商业媒体 > 平台讨论
```

平台讨论不能单独作为结论，只能作为需求和情绪信号。

时政信号：
