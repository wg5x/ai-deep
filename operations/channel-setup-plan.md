# Channel Setup Plan

> Date: 2026-06-07  
> Run: 005  
> Status: Recommendation  
> Purpose: Start from zero with the minimum channels needed to validate AI Opportunity Radar.

## 1. Goal

Create the smallest external presence that can support a real validation loop:

```text
publish sample
→ capture interest
→ book conversations
→ send briefs
→ record feedback
→ test willingness to pay
```

Do not start by building a full brand, community, dashboard, or product site.

## 2. Minimum Channel Stack

### 2.1 Public Landing Page

Purpose:

- explain the offer
- show the sample brief
- collect email or call interest

Recommended tools:

- Carrd for fastest lightweight page
- Framer if visual polish matters
- Notion/Super only if we want document-native speed

Recommendation:

```text
Use Carrd or Framer.
```

### 2.2 Newsletter / Email Capture

Purpose:

- collect interested people
- send sample and future briefs
- test subscription behavior

Recommended tools:

- Beehiiv if growth and newsletter tooling matter
- Substack if credibility and simple publishing matter
- Buttondown if minimal and developer-friendly matters

Recommendation:

```text
Start with Substack or Beehiiv.
```

For this project, Beehiiv is slightly better if we expect growth experiments. Substack is better if we want the easiest "publish a brief" workflow.

### 2.3 Booking Link

Purpose:

- let interested users book discovery calls

Recommended tools:

- Cal.com
- Calendly

Recommendation:

```text
Use Cal.com if we want open/flexible tooling.
Use Calendly if you already use it.
```

### 2.4 Public Social Account

Purpose:

- publish short AI opportunity takes
- test which angles get attention
- create surface area for replies and DMs

Recommended channels:

- X/Twitter for AI builders and investors
- LinkedIn for consultants, operators, and B2B buyers

Recommendation:

```text
Start with X/Twitter + LinkedIn only if you can tolerate both.
If choosing one, pick X/Twitter for builder discovery.
```

### 2.5 Feedback Form

Purpose:

- collect structured feedback from sample readers

Recommended tools:

- Tally
- Typeform
- Google Forms

Recommendation:

```text
Use Tally.
```

Do not overthink the domain.

Good enough options:

- `aiopportunityradar.com`

- `aiventureradar.com`

## 6. First 7-Day Channel Plan

Day 1:

- choose name
- create email/newsletter/booking/form
- publish sample brief privately or publicly

Day 2:

- create landing page draft
- add call-to-action:
  "Get the sample brief" and "Book a 20-minute feedback call"

Day 3:

- identify 10-20 targets
- score them with the target rubric

Day 4:

- send 5 warm outreach messages after approval

Day 5:

- send 5-10 more messages
- log responses

Day 6:

- run discovery calls or collect written feedback

Day 7:

- write validation memo
- decide continue, narrow, reposition, or stop

## 7. Do Not Create Yet

Avoid for now:

- Discord community
- paid ads
- full web app
- CRM
- analytics stack beyond basic visits/signups
- logo-heavy branding
- multi-language site
- complex automation

The bottleneck is not infrastructure. The bottleneck is whether real targets care.
