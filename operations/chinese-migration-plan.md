# 中文化迁移计划

> 日期：2026-06-07  
> 状态：计划  
> 目标：把项目从英文草稿阶段迁移到中文优先阶段

## 1. 背景

项目操作者在中国北京，主要渠道为小红书、B站、微信。因此后续文档、内容、实验记录应以中文为主。

早期英文文档保留了思考痕迹，不立即全部翻译，避免打乱上下文。后续按使用频率逐步中文化。

## 2. 优先级

| 优先级 | 文档类型 | 动作 |
|---|---|---|
| P0 | 运营内容、小红书、B站、微信话术 | 已经中文化，继续中文优先 |
| P0 | 账号注册、渠道策略、北京语境 | 已经中文化，继续维护 |
| P1 | mission 顶层使命 | 增补中文版本 |
| P1 | 商业实验文档 | 后续新增中文，旧英文可逐步补中文摘要 |
| P2 | 市场调研报告 | 需要中文摘要或中文版 |
| P2 | Deep Research Kernel 设计 spec | 需要中文摘要或中文版 |
| P3 | 历史 run log / changelog | 可保留英文，后续新增中文 |

## 3. 下一步建议

下一轮可以创建：

- `mission/autonomous-venture-loop.zh.md`
- `reports/001-ai-opportunity-intelligence-market-research.zh-summary.md`
- `docs/superpowers/specs/2026-06-07-deep-research-language-kernel-design.zh-summary.md`

## 4. 新文档命名

中文主文档可以直接使用中文内容，文件名仍保持 ASCII，便于工具处理。

例如：

```text
operations/account-registration-checklist.md
content/xiaohongshu/post-001-intro.md
mission/autonomous-venture-loop.zh.md
```
