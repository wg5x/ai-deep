# 下一步控制面板：摄影方向最小闭环

> 实验编号：004
> 子方向：摄影写真工作室
> 日期：2026-06-07
> 状态：内部准备完成，等待是否进入第一轮外部触达确认
> 默认动作：没有 P0 批准，不触达真实商家。

## 1. 当前结论

现在项目已经走到：

```text
能内部准备的，基本已经准备好。
下一步真正有价值的证据，来自真实商家是否愿意看样例、提问题、问价格或拒绝。
```

但这一步属于外部动作，所以不能静默执行。

当前最稳的下一步不是继续做更多材料，也不是接 Hermes/飞书/微信自动化，而是：

```text
由用户手动触达 3 个摄影候选，只问对方是否愿意看一页样例。
```

## 2. 我能多任务做什么

Agent 可以同时维护多个任务队列，但不同层级权限不同。

| 层级 | 可以静默做 | 是否需要用户确认 |
|---|---|---|
| L0 内部整理 | 项目文档、队列、复盘、风险边界 | 不需要 |
| L1 公开调研 | 公开候选、公开案例、开源工具、平台规则 | 不需要 |
| L2 草稿准备 | 样例、话术、报价、回复表、P0 草案 | 不需要 |
| L3 外部动作 | 私信、发邮件、加微信、发布、报价、收款 | 每次 P0 |
| L4 高风险动作 | 花钱、敏感信息、法律/医疗/金融/升学承诺 | 默认不做 |

所以“多任务模式”的真实结论是：

```text
我可以并行准备多个实验的内部材料。
我不能在没有批准时并行触达外部世界。
```

## 3. 当前可选动作

### 选项 1：批准第一轮手动触达

含义：

```text
用户手动复制发送给 3 个摄影候选。
Agent 不自动发送，不使用 Hermes，不使用机器人，不使用用户账号登录。
```

触达对象：

```text
1. 影纪摄影工作室
2. Cheer 喜阅摄影
3. Luyaophoto
```

本轮只问：

```text
你愿不愿意看一页样例？
```

本轮不做：

- 不发送样例，除非对方先回复愿意看，且再次 P0
- 不报价，除非对方先问价格，且按回复表处理
- 不收款
- 不加微信
- 不电话沟通
- 不承诺客流、成交、涨粉
- 不索要考生信息
- 不使用未授权照片

### 选项 2：继续内部准备

含义：

```text
不触达商家，继续把内部资产做得更稳。
```

可继续做：

- 把摄影样例改成“可直接发给商家看的版本”
- 补一份商家说“愿意看样例”后的 P0
- 准备餐饮/驾校两个备选方向对照
- 填一版 7 天验证复盘假设

### 选项 3：换方向

含义：

```text
暂停摄影方向，回到机会选择。
```

可换方向：

```text
1. 餐饮/升学宴/聚餐
2. 驾校/暑期学车
3. 世界杯观赛商家包
4. 先做通知通道/自动化运行时
```

### 选项 4：暂停

含义：

```text
不推进实验，只保留当前资产。
```

适合用户暂时不想消耗注意力时使用。

## 4. 推荐选择

推荐：

```text
1 批准第一轮手动触达
```

原因：

- 内部材料已经足够做一次小样本验证
- 继续打磨材料的边际收益下降
- 第一轮只问是否愿意看样例，风险较低
- 触达由用户手动执行，不引入自动化和账号风险
- 真实回复比继续脑补更能升级项目内核

## 5. 你可以直接回复

```text

3 换方向
4 暂停
```

如果回复 `1`，下一步只会输出 3 条可复制话术和记录方式；仍然不会自动发送。
