# 子方向对照：摄影 / 餐饮 / 驾校

> 实验编号：004
> 日期：2026-06-07
> 用途：解释为什么当前第一轮选摄影写真，而不是餐饮或驾校。

## 1. 当前排序

```text
第一轮：摄影写真
第二轮：餐饮/聚餐/升学宴
第三轮：驾校/暑期学车
```

这不是说摄影市场最大，而是说它更适合当前这个 7 天小实验。

## 2. 核心对照

| 维度 | 摄影写真 | 餐饮/聚餐 | 驾校/学车 |
|---|---|---|---|
| 买家清晰度 | 高，摄影工作室 | 高，餐饮店 | 中高，驾校或招生点 |
| 时间窗口 | 高考后到开学前 | 高考后、出分、录取 | 高考后到暑假 |
| 内容适配 | 很强，小红书/朋友圈直观 | 强，但容易像普通活动文案 | 中，需要解释流程和信任 |
| 客单空间 | 499-1999 元以上 | 商家客单低，营销包付费意愿需测 | 学费高，但招生链路重 |
| AI 交付杠杆 | 高，文案/主题/咨询话术可快速生成 | 高，菜单和套餐需要门店信息 | 中，合规和真实流程更重要 |
| 合规风险 | 未成年人肖像授权 | 高考焦虑/状元表达 | 包过、费用、资质承诺 |
| 第一轮信号 | 是否愿意看样例 | 是否愿意用活动文案 | 是否愿意聊招生内容 |
| 当前判断 | 最适合先测“愿意看样例” | 适合作为第二轮更广测试 | 适合后续更严谨验证 |

## 3. 为什么不是先做餐饮

餐饮更容易理解，但也有三个问题：

- 很多餐饮店已有团购、套餐和日常活动，节点内容的差异化可能不够强。
- 商家客单低，可能觉得 499/999 的内容包偏贵。
- 若没有菜单、空间、价格和可预约时间，样例容易变成通用文案。

餐饮适合作为第二轮，因为它可以更快扩大样本量。

## 4. 为什么不是先做驾校

驾校需求真实，但第一轮不优先，原因是：

- 招生涉及费用、资质、排期、练车地点和服务承诺，不能只靠文案。
- “包过”“快速拿证”等表达风险更高。
- 商家可能已有成熟招生链路，陌生内容包不一定能切进去。

驾校适合在拿到第一轮反馈后，再做更清楚的合规版本。

## 5. 为什么当前先做摄影

摄影适合第一轮，是因为：

- “高考后 18 岁纪念照”能被商家快速理解。
- 一页样例足以展示价值，不需要先拿大量门店资料。
- 内容平台适配度强，商家能直观看到小红书/朋友圈用途。
- 客单价相对更高，499/999 的服务测试更合理。
- 第一轮只问“愿不愿意看样例”，外部风险可控。

## 6. 当前风险

我看到一个风险：

```text
摄影方向容易碰到未成年人肖像和青春焦虑表达。
```

为什么这是风险：

```text
如果表达不谨慎，可能从“记录人生阶段”滑向“消费高考焦虑”或“未经授权展示未成年人照片”。
```

更稳的替代方案：

```text
第一轮只使用文字样例，不使用照片，不采集学生信息，不说成绩、录取、逆袭或状元。
```

需要你判断的地方：

```text
是否允许进入第一轮手动触达，获取真实商家反馈。
```

## 7. 选择规则

后续不是固定做摄影。

如果第一轮 3 个摄影候选都没有兴趣，下一步按以下规则转向：

```text
1. 如果商家不理解摄影节点，转餐饮，因为餐饮更直观。
2. 如果商家觉得样例有用但不愿付费，调整报价或交付边界。
3. 如果商家要求保证成交、学生数据或未授权照片，停止摄影方向。
4. 如果出现 1 个愿意看样例或问价格，继续摄影小样本。
```
