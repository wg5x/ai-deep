# 样例变体：餐饮 / 摄影 / 驾校

> 实验编号：004  
> 日期：2026-06-07  
> 用途：给不同商家快速展示“这件事和你有关”。

## 1. 餐饮店版本

### Campaign theme

```text
考完第一顿，认真庆祝一下
```

### Package names

```text
考完第一顿 4 人餐
青春不散场 6 人餐
录取见家庭庆祝餐
准大学生小聚套餐
```

### Xiaohongshu title

```text
北京高考后聚餐去哪儿？这顿饭先把压力放下
```

### WeChat copy

```text
高考结束后，第一顿饭不用太复杂。几个同学坐下来，好好吃、好好聊，就已经很值得庆祝。
```

### Best buyer

```text
适合有 4-8 人座位、适合同学聚餐或家庭庆祝的餐饮店。
```

## 2. 摄影写真版本

### Campaign theme

```text
18 岁这个夏天，给自己留一张正式照片
```

### Package names

```text
高考后 18 岁纪念照
毕业季青春写真
录取季纪念照
准大学生形象照
```

### Xiaohongshu title

```text
高考后想拍一组照片：不是为了别人，是为了记住这个夏天
```

### WeChat copy

```text
高考之后到开学之前，是很适合拍纪念照的一段时间。可以是一个人，也可以和好朋友一起，把这段青春认真留下来。
```

### Private reply

```text
可以先看你想要的风格：清爽校园、成人礼、轻写真、朋友合拍都可以。我们不使用未成年人照片做公开宣传，发布前会单独确认授权。
```

### Best buyer

```text
适合客单价较高、已有小红书内容、能承接学生/朋友合拍/家庭纪念的摄影工作室。
```

## 3. 驾校版本

### Campaign theme

```text
大学前，把学车这件事安排上
```

### Package names

```text
准大学生暑期学车计划
高考后学车时间表
开学前驾照准备包
学生暑期练车班
```

### Xiaohongshu title

```text
高考后到开学前，适不适合学车？先看这几个问题
```

### WeChat copy

```text
高考结束后到大学开学前，时间相对完整。如果本来就计划学车，可以先了解流程、费用、练车地点和暑期排期。
```

### Private reply

```text
可以先确认你所在区域、预计开学时间、是否能集中练车。我们会根据你的时间安排介绍合适班型，不承诺包过，也不催你马上报名。
```

### Best buyer

```text
适合有学生班型、能说清楚费用和练车地点、愿意做长期暑期获客的驾校或招生点。
```

## 4. Selection rule

第一轮优先级：

| Rank | Type | Why |
|---|---|---|
| 1 | 餐饮 | 最容易被商家理解，样例直观 |
| 2 | 摄影 | 客单价更高，内容平台适配度强 |
| 3 | 驾校 | 时间窗口更长，但信任和转化链路更重 |

## 5. Risk differences

| Type | Main risk | Safer phrasing |
|---|---|---|
| 餐饮 | 状元/录取暗示 | 考后放松、同学小聚、家庭庆祝 |
| 摄影 | 未成年人肖像 | 发布前授权，不公开未授权照片 |
| 驾校 | 包过承诺 | 流程介绍、时间安排、费用透明 |
