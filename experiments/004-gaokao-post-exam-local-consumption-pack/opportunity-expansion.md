# 机会扩展：高考后本地消费

> 实验编号：004  
> 日期：2026-06-07  
> 方法：强脑暴 → 1 → 10 → 100 → 3 → 1

## Seed

用户决定不启用书法朋友资源，需要换一个不依赖熟人关系的商业实验。

选定种子：

```text
高考后本地消费
```

## Why it matters

高考后，家庭和学生的状态从紧张转向释放、选择、庆祝和准备。

这不是一个行业，而是一串钱流动的节点。

## Opportunity clusters

### Cluster A: 考后聚餐和同学局

适合餐饮店、烧烤店、火锅店、甜品店、桌游店。

核心卖点：

```text
考完第一顿 / 同学散伙饭 / 家庭庆祝小套餐
```

### Cluster B: 毕业写真和成人礼纪念

适合摄影工作室、妆造、服装租赁、轻旅拍。

核心卖点：

```text
18 岁纪念 / 高考后写真 / 录取季纪念照
```

### Cluster C: 暑期学车和准大学生技能

适合驾校、英语口语、运动健身、形象管理、办公软件课程。

核心卖点：

```text
大学前把这件事搞定
```

### Cluster D: 录取庆祝和升学宴

适合宴会餐厅、酒店、本地礼品、花店、蛋糕店。

核心卖点：

```text
录取通知书到了之后的家庭庆祝
```

### Cluster E: 入学装备和数码零售

适合电脑店、手机店、行李箱、文具、床品、学习设备。

核心卖点：

```text
准大学生入学装备清单
```

## Ranked experiments

| Rank | Experiment | Reason |
|---|---|---|
| 1 | 高考后本地消费营销包 | 合规风险低，商家清楚，7 天可验证 |
| 2 | 录取季升学宴/礼品营销包 | 7-8 月窗口更长，适合后续 |
| 3 | 准大学生入学装备内容包 | 可做内容和导购，但商家触达更分散 |

## First cash-flow offer

```text
高考后/录取季 7 天获客包：
帮北京本地商家快速做一套活动主题、套餐包装、小红书/朋友圈内容和私域承接话术。
```

第一测试价格：

```text
499 元轻量包
999 元定制包
1999 元 7 天陪跑包
```

## Risks

- 高考相关表达敏感，不能制造焦虑。
- 部分目标人群未成年，不能采集或滥用个人信息。
- 商家可能只想拿免费文案，不愿付费。
- 窗口短，执行要快。
- 太泛会卖不动，必须按商家类型出样例。

## Selection

先做餐饮/摄影/驾校三个版本样例。

原因：

```text
餐饮最容易理解，摄影客单价更高，驾校暑期窗口更长。
```
