# 商家回复处理表

> 实验编号：004
> 用途：外部触达经用户批准后，记录商家不同回复的处理方式。
> 当前状态：内部准备，不触达。

## 1. 回复分类

| 类型 | 商家回复 | 判断 | 下一步 |
|---|---|---|---|
| A | 愿意看样例 | 有初步兴趣 | 发送一页样例前再次确认是否已获触达批准 |
| B | 问多少钱 | 有商业可能 | 简述测试价 499/999，但不承诺效果 |
| C | 要看真实案例 | 信任不足 | 说明当前是测试期，可先看匿名样例 |
| D | 说不需要 | 弱信号 | 追问一句不适合原因，记录后停止 |
| E | 已有代运营 | 买家有预算但竞争存在 | 问是否需要节点内容补充，记录 |
| F | 要保证客流/成交 | 高风险 | 明确不能承诺，停止夸大方向 |
| G | 要学生/考生数据 | 高风险 | 拒绝，不采集敏感信息 |
| H | 要电话/微信详聊 | 外部沟通升级 | 必须回到用户 P0 确认 |

## 2. 回复模板

### A. 愿意看样例

```text
可以，我先发一页样例给你看。

这页不是让你马上购买，主要是看这个方向是否贴合你们店。如果你觉得不适合，也可以直接告诉我哪里不对。
```

边界：

```text
发送真实样例前必须已有用户批准。
```

### B. 问多少钱

```text
现在是测试期，轻量包是 499，定制包是 999。

轻量包主要是主题、套餐名、小红书/朋友圈文案、私信回复和 7 天执行清单。
定制包会按你们店的真实风格和服务做两套方案，并包含一次修改。

不承诺客流或成交，只交付可发布、可沟通、可执行的内容材料。
```

### C. 要看真实案例

```text
理解。这个方向现在还在小样本测试，所以我不会夸大说已经有很多案例。

我可以先给你看一页匿名样例，你只判断它对你有没有用。
```

### D. 说不需要

```text
明白，不打扰。

方便的话我只想问一句：是不需要高考后/毕业季这个方向，还是你们已经有自己的内容和活动安排？
```

如果不再回复，停止。

### E. 已有代运营

```text
那挺好，说明你们已经有人负责内容。

我这个更像一个节点内容补充包，不替代代运营。比如高考后 18 岁纪念照、准大学生形象照、朋友合拍这些主题，帮你们快速补一组可发内容。

如果这类补充也不需要，我就不打扰。
```

### F. 要保证客流/成交

```text
这个我不能承诺。

我能交付的是活动包装、内容文案和咨询回复材料，帮助你们更快把这个节点表达清楚。但实际咨询和成交会受门店、价格、平台流量、服务质量影响。
```

如果商家继续要求保证结果，停止。

### G. 要学生/考生数据

```text
这个不能做。

我们不采集考生或未成年人敏感信息，也不提供这类数据。这个服务只做公开内容和私域话术整理。
```

立即停止该方向并记录风险。

### H. 要电话/微信详聊

```text
可以，我先确认一下时间和沟通方式，再回复你。
```

边界：

```text
进入电话、微信或用户真实身份沟通前，必须回到用户 P0 确认。
```

## 4. 升级为 P0 的情况

出现以下情况必须通知用户：

- 商家愿意电话/微信详聊
- 商家询问付款方式
- 商家要求定制报价
- 商家愿意提供真实门店信息
- 商家要求使用真实作品/照片
- 商家要求保证效果
- 商家涉及考生、未成年人或敏感数据

## 5. 停止规则

立即停止：

- 要求保证成交
- 要求考生数据
- 要求绕过授权使用照片
- 诱导夸大高考结果
- 要求冒充官方合作

停止后只记录，不争辩。
