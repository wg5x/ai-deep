# 摄影候选适配角度

> 实验编号：004
> 子方向：摄影写真工作室
> 状态：内部候选适配，不触达、不背书、不推荐。

## 1. 影纪摄影工作室

公开信号：

```text
素人改造、私人订制写真、北京约拍
```

适配角度：

```text
高考后 18 岁纪念照 / 准大学生第一组正式照片
```

样例切入：

- 强调“刚结束一段努力，记录新阶段开始”
- 用清爽自然风格，避免过度成人化或焦虑化
- 私信话术重点放在风格沟通、服装建议、授权边界

第一句触达草案：

```text
你好，我看到你们有素人改造和私人订制写真方向，感觉很适合做一版“高考后 18 岁纪念照”的内容样例。
```

风险：

- 需严格处理未成年人肖像授权
- 不使用“考得好才值得拍”等表达

## 2. Cheer 喜阅摄影

公开信号：

```text
肖像、写真、全家福
```

适配角度：

```text
准大学生形象照 + 录取季家庭纪念照
```

样例切入：

- 同时覆盖学生和家庭场景
- 可把“个人形象照”和“家庭纪念”做成两个套餐名
- 更适合客单价较高、重品质表达的样例

第一句触达草案：

```text
你好，我看到你们有肖像、写真和全家福方向，想试做一版“准大学生形象照/录取季家庭纪念照”的一页样例。
```

风险：

- 家庭庆祝表达不要暗示录取结果
- 不承诺转化，只展示内容包装价值

## 3. 和颐轩

公开信号：

```text
汉服、洛丽塔、少女风、线下活动
```

适配角度：

```text
考后国风写真 / 朋友合拍纪念
```

样例切入：

- 差异化强，适合做“小众但好传播”的样例
- 内容标题可偏“这个夏天认真留下自己”
- 适合朋友合拍、国风体验、毕业季纪念

第一句触达草案：

```text
你好，我看到你们有汉服和少女风拍摄方向，感觉可以做一版“考后国风写真/朋友合拍”的内容样例。
```

风险：

- 少女风和未成年人场景要更谨慎
- 不使用未经授权照片做展示

## 4. Luyaophoto

公开信号：

```text
北京胶片写真、肖像写真、家庭摄影
```

适配角度：

```text
18 岁胶片纪念照 / 高考后自然肖像
```

样例切入：

- 胶片感适合“记住这个夏天”的情绪表达
- 可突出自然、轻松、真实，而不是强营销
- 适合做更审美化的一页样例

第一句触达草案：

```text
你好，我看到你们有胶片写真和肖像方向，想试做一版“18 岁胶片纪念照”的高考后内容样例。
```

风险：

- 不把高考成绩和拍照价值绑定
- 避免过度消费青春焦虑

## 第一轮顺序建议

```text
1. 影纪摄影工作室
2. Cheer 喜阅摄影
3. Luyaophoto
```

原因：

- 三者都能承接个人肖像/写真
- 样例可以共用 70% 结构，只需改风格
- 比和颐轩的风格风险更低

和颐轩保留为差异化候选，不作为第一批 3 个。
