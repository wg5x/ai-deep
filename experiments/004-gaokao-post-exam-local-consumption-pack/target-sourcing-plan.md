## 1. Target categories

第一批只找三类：

```text

```

## 4. Qualification rubric

每个候选商家打分：

| Factor | Score |
|---|---:|
| 是否明显适合高考后消费 | 0-2 |
| 是否有公开联系方式或私信入口 | 0-2 |
| 是否正在做内容 | 0-2 |
| 是否有可包装产品/套餐 | 0-2 |
| 是否合规风险低 | 0-2 |

优先触达：

```text
总分 >= 7
```
