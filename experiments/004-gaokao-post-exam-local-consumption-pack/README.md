转成北京本地商家愿意付费的小型营销服务。

## Why This Replaces Experiment 003

Experiment 003 依赖私人关系资源。用户已经明确不想启用该资源。

Experiment 004 改用公开市场：

- 不依赖熟人
- 不需要用户消耗私人关系
- 可在北京公开寻找候选商家
- 可以复用到其他季节性事件
- 适合用 499/999 元快速验证第一笔现金流

## External Action Boundary

在用户明确批准前：

- 不私信真实商家
- 不发布公开内容
- 不承诺销售结果
- 不收款
- 不采集考生或未成年人敏感信息
- 不提供志愿填报、录取预测或升学保证

## Core Bet

```text
高考后的钱，不只流向志愿填报。
它还流向聚餐、旅行、写真、驾校、数码、升学宴、暑期体验和入学准备。
```

AI 的位置不是替家庭做升学决策，而是帮本地商家更快抓住这些消费窗口。
