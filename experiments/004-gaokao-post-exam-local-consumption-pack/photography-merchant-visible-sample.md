# 商家可看样例草案：高考后 18 岁纪念摄影写真

> 实验编号：004
> 子方向：摄影写真工作室
> 日期：2026-06-07
> 状态：待 P0 批准后才可发送给真实商家
> 用途：当商家回复“愿意看一页样例”后，给用户审批是否发送。

## 发送边界

这份样例只能在以下条件同时满足时发送：

- 用户已批准第一轮外部触达
- 商家已明确回复愿意看样例
- 用户再次批准发送样例
- 发送时不附带报价、收款方式或成交承诺
- 不使用任何未授权照片、真实学生信息或商家私有素材

## 给商家的开场说明

```text
这是一个一页样例，不是正式方案，也不要求你现在购买。

我想测试的是：高考后到大学开学前，“18 岁纪念照/准大学生形象照/朋友合拍”这个节点，是否适合你们店做内容包装和咨询承接。

这里不承诺客流或成交，也不使用未授权照片。你只需要判断：这个方向对你们店有没有用，哪里不贴合。
```

## 一页样例

### 活动主题

```text
18 岁这个夏天，给自己留一张正式照片
```

### 适合场景

```text
1. 高考后 18 岁纪念照
2. 准大学生形象照
3. 毕业季朋友合拍
4. 录取季家庭纪念照
```

### 套餐命名建议

```text
1. 18 岁纪念照
2. 准大学生形象照
3. 高考后轻写真
4. 朋友合拍纪念套系
5. 录取季家庭纪念照
```

### 小红书标题

```text
高考后想拍一组照片：不是为了别人，是为了记住这个夏天
```

### 小红书正文

```text
高考结束后到大学开学前，是很特别的一段时间。

它不像毕业典礼那么正式，也不像开学以后那么忙。你刚刚结束一段很长的努力，正站在一个新的阶段门口。

可以给自己拍一组轻松一点的照片：一套干净的衣服、一点自然的妆发、几张能让以后想起来这个夏天的照片。

可以一个人拍，也可以和好朋友一起拍。风格不用太复杂，清爽、自然、像自己就很好。

如果你想拍 18 岁纪念照、准大学生形象照或朋友合拍，可以先私信说说你喜欢的风格。
```

### 朋友圈文案

```text
高考结束后的这个夏天，很适合给自己留一组正式照片。

可以是 18 岁纪念照，也可以是和朋友一起的毕业季合拍。

不需要夸张造型，清爽、自然、像自己，就很值得留下。

大学开学前，如果想拍一组准大学生形象照，可以提前约时间。
```

### 咨询回复示例

```text
Q: 刚高考完可以拍吗？
A: 可以。高考后到开学前时间比较完整，很适合拍 18 岁纪念照或准大学生形象照。

Q: 可以和朋友一起拍吗？
A: 可以。朋友合拍可以做清爽校园风、轻写真或胶片感，具体看你们喜欢的风格。

Q: 家长可以一起拍吗？
A: 可以。如果想做家庭纪念照，也可以单独安排更自然的家庭记录风格。

Q: 照片会公开发吗？
A: 不会默认公开。任何照片用于公开展示前，都需要本人和监护人明确授权。
```

## 想请商家反馈的问题

发送样例后，只问三个问题：

```text
1. 这个方向对你们店有没有用？
2. 哪个场景更像你们能承接的业务？
3. 如果要按你们店真实情况改，最需要改哪里？
```

## 禁止追加

发送这份样例时，不追加：

- 价格
- 收款码
- 微信号
- 电话沟通邀约
- “保证咨询/保证成交”
- “可以帮你们找学生”
- “有考生资源”

如果商家主动问价格、定制、电话或微信，进入 `merchant-reply-handling.md`，并再次 P0。
