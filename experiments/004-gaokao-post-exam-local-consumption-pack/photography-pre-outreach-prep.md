# 摄影方向正式触达前准备包

> 实验编号：004
> 子方向：摄影写真工作室
> 状态：触达前内部准备完成
> 用户授权：仅内部准备，不触达
> 决策记录：`memory/decisions/2026-06-07-exp004-photography-internal-prep.md`

## 1. 当前目标

把摄影方向准备到“可以请求用户批准触达”的状态。

当前不执行：

- 不私信商家
- 不发送样例
- 不报价
- 不收款
- 不使用用户账号
- 不启用熟人关系

## 2. 第一轮建议触达对象

正式触达前建议只选 3 个候选。

| 顺序 | 候选 | 公开信号 | 触达理由 | 第一消息角度 |
|---:|---|---|---|---|
| 1 | 影纪摄影工作室 | 素人改造、私人订制写真、北京约拍 | 与 18 岁纪念照高度贴合 | 高考后 18 岁纪念照 |
| 2 | Cheer 喜阅摄影 | 肖像、写真、全家福 | 可覆盖个人和家庭场景 | 准大学生形象照/录取季家庭纪念 |
| 3 | Luyaophoto | 胶片写真、肖像、家庭摄影 | 审美化表达强，适合情绪型内容 | 18 岁胶片纪念照 |

和颐轩暂不进入第一轮，原因：

```text
风格更小众，且少女风/未成年人肖像风险更高。
```

## 3. 触达方式建议

第一轮只建议：

```text
用户手动复制发送。
```

不建议：

- Agent 自动发送
- Hermes 发送
- 飞书/机器人发送
- 批量私信
- 使用陌生营销工具

理由：

```text
第一轮测试的是话术和需求，不是自动化能力。
```

## 4. 第一轮触达内容

### 4.1 影纪摄影工作室

```text
你好，我看到你们有素人改造和私人订制写真方向，感觉很适合做一版“高考后 18 岁纪念照”的内容样例。

高考后到大学开学前，会有一些学生想拍 18 岁纪念、准大学生形象照或朋友合拍。
我在做一个北京本地摄影店的节点内容小实验，可以帮店里整理一页活动主题、小红书文案、朋友圈文案和私信回复。

不承诺客流，也不使用未授权照片，只是先把这个节点包装成可以发布和承接咨询的内容。

如果你愿意，我可以发一页样例，你看有没有用。
```

### 4.2 Cheer 喜阅摄影

```text
你好，我看到你们有肖像、写真和全家福方向，想试做一版“准大学生形象照/录取季家庭纪念照”的一页样例。

高考结束后到大学开学前，有些家庭会想给孩子拍一组更正式的照片，也可能顺便拍一组家庭纪念。
我可以帮店里把这个节点整理成活动主题、小红书/朋友圈文案和咨询回复话术。

不承诺成交，也不碰升学承诺，只做内容包装和私域承接材料。

如果你愿意，我可以先发一页样例，你判断是否适合你们店。
```

### 4.3 Luyaophoto

```text
你好，我看到你们有胶片写真和肖像方向，想试做一版“18 岁胶片纪念照”的高考后内容样例。

这个方向不是制造焦虑，而是把高考后到开学前这段时间，包装成一个自然、轻松、能被记录的拍摄场景。
我可以帮店里整理一页主题、套餐名、小红书文案、朋友圈文案和私信回复。

不承诺流量或成交，也不默认公开任何未授权照片。

如果你愿意，我可以发一页样例，你看有没有用。
```

## 5. 第一轮只问一个问题

第一轮触达目标不是成交。

只问：

```text
你愿不愿意看一页样例？
```

不主动报价，除非商家先问价格。

不主动索要门店资料，除非商家表示愿意继续。

不主动加微信或电话，除非商家提出，并回到用户 P0 确认。

## 6. 发送前检查清单

发送前必须确认：

- 用户已明确批准本轮触达
- 触达对象不超过 3 个
- 触达方式为用户手动复制发送
- 不使用 Agent/Hermes/机器人自动发送
- 不承诺客流、成交、涨粉
- 不涉及志愿填报、录取预测、升学保证
- 不索要考生敏感信息
- 不要求使用未成年人照片
- 不报价，除非对方主动问
- 回复后按 `merchant-reply-handling.md` 处理

## 7. 回复记录方式

每条回复写入：

```text
feedback-log.csv
```

如果出现报价、付费、转介绍等信号，再写入：

```text
conversion-log.csv
```

## 8. 成功与停止

第一轮成功信号：

- 3 个候选中有 1 个愿意看样例
- 有商家问价格
- 有商家愿意提供门店信息
- 有商家指出样例哪里不适合

立即停止：

- 要求保证成交
- 要求学生/考生数据
- 要求未经授权使用照片
- 要求冒充官方/学校/高考合作
- 出现平台或声誉风险
