# Outreach Execution Plan

> Experiment: 001  
> Run: 004  
> Status: Ready for candidate review  
> External contact: Not executed

## 1. Objective

Validate whether AI Opportunity Radar creates enough interest to justify continuing.

## 2. Batch Size

Start with:

```text
10-20 qualified targets
```

## 3. Primary Ask

The first ask is not payment.

The first ask is:

```text
Would you read one sample brief and tell me whether this would be useful for your work?
```

## 4. Strong Signal

Strong signal:

- target asks for the sample
- target gives specific feedback
- target books a call
- target asks for a custom version
- target expresses willingness to pay

## 5. Weak Signal

Weak signal:

- no reply
- generic praise
- says it is interesting but not useful
- compares it to free AI newsletters
- cannot identify a use case

## 6. Decision After Batch 1

After the first batch:

```text
Continue if:
  3+ meaningful replies or 1+ payment-intent signal.

Revise if:
  replies are positive but positioning is unclear.

Stop if:
  no meaningful replies and no clear objection pattern.
```

## 7. Artifacts To Update After Outreach

- `feedback-log.csv`
- `conversion-log.csv`
- `validation-memo-template.md`
- `memory/kernel-changelog/`

## 8. External Approval Gate

Human approval is required before any message is sent.
