# 触达话术：世界杯观赛获客包

> 实验编号：002  
> 状态：待用户批准后才能用于真实触达

## 1. 微信/私信短版

```text
你好，我在做一个北京本地商家的世界杯观赛活动小实验。

世界杯 6 月 11 日开赛，我看你们店比较适合做看球/朋友小聚场景。
我可以帮你们做一套 7 天观赛获客包：活动主题、套餐文案、小红书/朋友圈内容、私信预约话术都配好。

不是卖课，也不承诺营业额，就是帮店里更快把这波热点包装出来。
我可以先发你一页样例，你看有没有用。
```

## 2. 熟人介绍版

```text
我最近在做一个 AI 商业实验室的小项目，专门帮本地商家把热点转成可执行的营销方案。

世界杯马上开始，我想先找 3-5 家北京店试一下。
如果你认识适合看球的餐饮/酒吧/咖啡馆老板，我可以免费先给他看一页样例。
如果觉得有用，再按 499/999 做完整包。
```

## 3. 店主回复“多少钱”

```text
现在是第一轮小实验，价格很轻：

499 元：轻量包，活动主题、套餐建议、3 条小红书、5 条朋友圈、私信话术和执行清单。
999 元：增强包，会按你们店的菜单/环境定制，并加 7 天内容排期和一次修改。

不承诺营业额，只交付可马上发布和执行的内容方案。
```

## 4. 店主回复“先看看”

```text
可以。我先发你一页样例，你主要看三件事：

1. 这个活动你们店能不能执行；
2. 文案像不像你们会发的内容；
3. 如果定制成你们店的版本，值不值得花 499/999。

你看完直接说真实感受就行。
```

## 5. 店主回复“没兴趣”

```text
明白，谢谢你直接说。

方便问一句，是因为你们已经有世界杯活动了，还是觉得这类方案对店里没帮助？
我在做验证，真实反馈对我很重要。
```

## 6. 风险边界

不要说：

- 保证爆单
- 官方合作
- 赌球/竞猜
- 低成本躺赚
- 不用你管我全包
