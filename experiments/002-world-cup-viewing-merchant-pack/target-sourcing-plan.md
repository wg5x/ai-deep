# 目标商家寻找计划

> 实验编号：002  
> 日期：2026-06-07  
> 外部动作：未执行

## 1. 目标画像

优先找具备以下特征的北京商家：

- 有屏幕、投影或适合聚集看球的空间
- 已经做过节日/赛事/主题活动
- 小红书、朋友圈或社群运营较活跃
- 老板/店长可直接沟通
- 客单价能覆盖活动运营成本
- 适合 2-8 人小聚

## 2. 优先类型

| 优先级 | 类型 | 理由 |
|---|---|---|
| P1 | 精酿/清吧/酒吧 | 观赛场景自然，付费动机强 |
| P1 | 烧烤/夜宵/小龙虾 | 世界杯和夜经济相关 |
| P2 | 咖啡馆/活动空间 | 适合非球迷社交场景 |
| P2 | 桌游店/社群空间 | 适合小团体预约 |
| P3 | 普通餐饮店 | 需要判断是否有屏幕和氛围 |

## 4. 记录字段

```csv
name,type,area,source,has_screen,active_on_social,fit_score,contact_path,status,notes
```

## 5. 筛选标准

`fit_score` 1-5 分：

- 5：明显适合观赛，有社交媒体和联系方式
- 4：空间/品类适合，但未看到活动
- 3：可能适合，需要确认
- 2：弱相关
- 1：不适合

## 6. 外部动作边界

在用户明确批准前：

- 只收集公开信息
- 不私信
- 不电话
- 不加微信
- 不发布公开内容
- 不承诺合作
