# Experiment 002: World Cup Viewing Merchant Pack

本实验用于验证：

```text
AI 商业实验室能否把世界杯这类现实事件，快速转成北京本地商家愿意付费的小服务。
```

## Files

- `market-signal.md`：市场信号
- `experiment-brief.md`：实验简报
- `offer.md`：报价与服务包装
- `delivery-template.md`：交付模板
- `sample-one-page-pack.md`：一页样例
- `target-sourcing-plan.md`：目标商家寻找计划
- `outreach-script.md`：触达话术
- `outreach-tracker.csv`：触达记录
- `feedback-log.csv`：反馈记录
- `conversion-log.csv`：转化记录
- `validation-memo-template.md`：复盘模板

## External Action Boundary

在用户明确批准前：

- 不私信真实商家
- 不发布公开内容
- 不承诺合作
- 不收款
- 不使用任何误导性世界杯官方授权表达
