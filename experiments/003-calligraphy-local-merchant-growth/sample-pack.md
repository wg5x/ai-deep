# 一页样例：书法体验课获客包装

> 样例对象：北京某书法老师  
> 状态：等待真实信息后定制  
> 注意：此为示例，不代表真实朋友情况。

## 1. 定位候选

```text
北京周末书法体验课：
给想放慢节奏的成年人，提供 90 分钟安静、上手、可带走作品的书法体验。
```

备选定位：

- 亲子书法体验：周末和孩子一起写一幅作品
- 暑期少儿书法启蒙：从坐姿、握笔和基本笔画开始
- 成人减压书法课：把手机放下，写一小时字

## 2. 体验课主题

```text
写一幅属于自己的“静”字
```

活动卖点：

- 不要求基础
- 90 分钟体验
- 老师现场指导
- 结束带走一幅作品
- 适合成人/亲子/朋友同行

## 3. 小红书笔记样例

标题：

```text
北京周末书法体验，写字真的能让人安静下来
```

正文：

```text
如果你最近总觉得脑子很吵，可以试试写一小时字。

不用有基础，也不用写得多好。
从坐下来、拿起笔、慢慢写第一个笔画开始，人会一点点安静下来。

这次体验课会带你完成一幅可以带走的小作品，适合一个人来，也适合和朋友/孩子一起。

地点在北京，想了解时间可以私信我。
```

评论引导：

```text
你想写哪个字？我可以帮你看看适不适合第一次体验。
```

问：没基础可以吗？

```text
可以，体验课就是给零基础准备的，会从握笔、坐姿和简单笔画开始。
```

问：孩子可以来吗？

```text
可以，但需要看孩子年龄和专注时间。如果是亲子体验，家长一起参与会更好。
```

问：能带走作品吗？

```text
可以，体验课会设计一个适合初学者完成的小作品。
```
