
## Pivot Note

本实验不删除，因为它沉淀了一个重要教训：

```text
真实关系资源很有价值，但只有在用户愿意启用、社会成本可控、关系压力可控时才应优先。
```

后续实验默认增加一个判断：

```text
这个资源是否值得动用？用户是否舒服？不用它是否也能推进验证？
```
