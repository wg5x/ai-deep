# 机会扩展：书法朋友

> 实验编号：003  
> 日期：2026-06-07  
> 方法：强脑暴 → 1 → 10 → 100 → 3 → 1

## 1. Seed

用户有一个做书法的朋友，并愿意用个人微信承接早期反馈。用户优先想做本地商家方向。

## 2. Why it matters

这是第一个真实资源，不是陌生市场假设。

相比随机找商家，书法朋友具备：

- 可沟通
- 可快速拿资料
- 可低风险试样例
- 可获得真实反馈
- 可验证本地文化教育商家的获客痛点

## 3. 10 surfaces

| Surface | Direction |
|---|---|
| 少儿书法 | 暑期班、基础班、考级、习惯培养 |
| 成人兴趣 | 减压、修身、国风审美、周末体验 |
| 亲子体验 | 家长陪孩子共同体验传统文化 |
| 企业活动 | 团建、文化沙龙、节日活动 |
| 礼品作品 | 题字、扇面、对联、祝福卡、毕业礼 |
| 节日节点 | 端午、七夕、中秋、春节、教师节 |
| 升学节点 | 高考后、录取后、毕业季、入学礼 |
| 内容账号 | 小红书/B站/视频号书法内容获客 |
| 本地空间 | 社区、咖啡馆、书店、文化空间联名 |
| AI 工具 | 文案、课程包装、作品故事、私域话术 |

## 4. Materials to collect

向朋友收集：

- 是否有线下空间
- 当前主卖课程或作品
- 目标人群
- 价格
- 过往作品照片
- 是否能做体验课
- 是否能做亲子/成人/企业活动
- 当前获客渠道
- 最大痛点
- 不愿意做的方向

## 5. Opportunity clusters

### Cluster A: 体验课获客

```text
把书法朋友包装成“北京周末书法体验课/亲子书法体验/成人减压书法课”。
```

### Cluster B: 暑期少儿书法班

```text
围绕暑期、习惯培养、传统文化素养做招生内容。
```

### Cluster C: 作品/礼品定制

```text
围绕录取祝福、乔迁、开业、节日礼品做作品转化。
```

### Cluster D: 企业/社群文化活动

```text
给公司、社群、书店、咖啡馆做一场书法体验沙龙。
```

## 6. Ranked experiments

| Rank | Experiment | Reason |
|---|---|---|
| 1 | 周末书法体验课包装包 | 最轻，适合本地商家，能快速验证 |
| 2 | 暑期少儿书法招生内容包 | 时间窗口强，但涉及家长信任 |
| 3 | 录取季书法祝福礼品包 | 高考链路相关，适合小单 |

## 7. First cash-flow offer

先不直接向终端学生收费。

第一笔钱可以来自：

```text
朋友本人为获客包装服务付 499/999；
或者朋友同意试用，我们以成交后分成/反馈换样例。
```

## 8. Risks

- 书法朋友可能不是商业化运营状态。
- 如果主要教少儿，涉及未成年人信息和家长信任。
- 课程效果不能夸大。
- 内容不能变成低质“国学焦虑”营销。

## 9. Next action

用户先向朋友确认 10 个基础问题。

Agent 根据回答生成：

```text
1 页店铺/老师定位
3 条小红书内容
1 个体验课活动方案
1 套微信私域话术
```
