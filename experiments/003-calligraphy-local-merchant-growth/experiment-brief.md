# 实验简报：书法朋友本地商家增长包

> 实验编号：003  
> 日期：2026-06-07  
> 类型：小实验  
> 周期：1-7 天  
> 外部动作：未执行

## 1. Opportunity

用户有一位做书法的朋友。该资源可以作为 AI 商业实验室的第一个真实本地商家样本。

## 2. Experiment size

小实验。

目标不是立刻做大，而是验证：

```text
AI 能否帮助一个本地文化/兴趣教育商家，用低成本完成定位、内容、活动和私域转化包装。
```

## 3. Target buyer

第一目标：

```text
书法老师/书法工作室/书法相关本地商家
```

第二目标：

```text
其他本地兴趣教育商家，如美术、茶艺、围棋、非遗体验、成人兴趣课。
```

## 4. Pain or desire

可能痛点：

- 有作品和教学能力，但不会包装
- 不知道小红书怎么发
- 不知道体验课怎么设计
- 不知道朋友圈/微信群怎么承接
- 不知道成人、亲子、少儿、企业活动哪个更适合

## 5. Why now

当前临近暑期，少儿兴趣课、亲子活动、成人周末体验和高考后放松消费都有机会。

## 6. Leverage available

- 用户已有真实朋友关系
- 朋友已有书法技能和作品
- 可以借小红书/朋友圈/微信承接
- 可以借 AI 生成内容、活动方案、话术和视觉方向
- 可以先用文档/图片样例交付，不做系统

## 7. Small-boat test

```text
先不开发工具。
先不投广告。
先不做复杂品牌。
用 1 页样例包问朋友：这是否能帮你获客，是否愿意试。
```

## 8. Offer

```text
书法本地获客包装包：
帮书法老师/工作室做一套体验课活动、内容和私域转化材料。
```

## 9. Price or value exchange

第一价格：

```text
499 元：基础包装包
999 元：定制增强包
```

如果朋友不适合直接付费：

```text
免费试一版，换真实反馈和允许匿名沉淀案例。
```

## 10. Delivery method

文档/微信交付：

- 老师/工作室定位
- 体验课主题
- 小红书内容 3 条
- 朋友圈文案 5 条
- 私域咨询话术 10 条
- 活动页文案
- 风险提醒

## 11. AI leverage

- 快速生成不同定位
- 根据作品照片生成内容角度
- 根据目标人群生成课程包装
- 生成私域问答
- 生成一周内容排期

## 12. Acquisition path

第一步：

```text
用户私下问朋友 10 个问题。
```

第二步：

```text
Agent 根据回答做一页样例。
```

第三步：

```text
用户给朋友看样例，收集真实反馈。
```

## 13. 7-day actions

| Day | Action |
|---|---|
| D1 | 用户向朋友确认基础信息 |
| D2 | Agent 生成一页样例包 |
| D3 | 用户给朋友看样例 |
| D4 | 根据反馈改定位和报价 |
| D5 | 尝试让朋友发布 1 条朋友圈/小红书或介绍另一个商家 |
| D6 | 记录咨询/反馈 |
| D7 | 复盘是否进入 499/999 付费包 |

## 14. Success threshold

任一成立即可继续：

- 朋友认为样例有用
- 朋友愿意提供作品/课程信息
- 朋友愿意发一条内容测试
- 朋友愿意付 499/999
- 朋友愿意介绍另一个本地商家

## 15. Failure threshold

- 朋友没有商业化意愿
- 内容无法表达其真实风格
- 朋友不愿提供素材
- 目标人群不清楚
- 课程/作品没有可售卖形态

## 16. Risks

- 不承诺招生结果。
- 不夸大书法学习效果。
- 不使用未成年人照片或隐私信息。
- 不制造家长焦虑。
- 不代替老师做教学承诺。

## 17. What will be learned

```text
真实本地兴趣教育商家是否需要 AI 辅助获客包装？
499/999 元服务是否合理？
用户个人微信承接是否可行？
```
