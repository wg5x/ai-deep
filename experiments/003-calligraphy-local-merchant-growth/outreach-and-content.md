# 内容与触达材料：书法本地获客包装

> 实验编号：003  
> 状态：草稿，未发布

## 1. 用户给朋友的开场

```text
我最近在做一个 AI 商业实验室的小实验，不是卖课，也不是让你马上花钱。

我想先帮身边真实的小商家做一版获客包装样例。
你做书法，我觉得很适合试一版：定位、体验课主题、小红书内容、朋友圈文案、咨询话术。

你回答我几个问题，我先做一页样例给你看。你觉得没用也直接说，这对我也是反馈。
```

## 2. 小红书方向

### 成人减压

```text
北京周末书法体验：写字真的能让人慢下来
```

### 亲子体验

```text
周末和孩子一起写一幅字，比逛商场安静多了
```

### 暑期少儿

```text
暑假不只补课，也可以让孩子练一练专注力
```

### 作品礼品

```text
录取通知书到了，可以写一幅有纪念意义的字
```

## 3. 朋友圈方向

```text
这个周末开一场小型书法体验。
不用基础，适合成人放松，也适合亲子一起写。
名额不多，想来的朋友可以私信我。
```

## 4. 私域咨询问题

- 没基础能不能来？
- 孩子多大适合？
- 一次课多久？
- 能不能带走作品？
- 在哪里？
- 多少钱？
- 有没有长期课？
- 能不能定制作品？

## 5. 可测试活动

```text
活动名：周末写一个“静”字
人数：3-6 人
时长：90 分钟
对象：成人/亲子
交付：带走一幅小作品
价格：由朋友真实情况决定
```
