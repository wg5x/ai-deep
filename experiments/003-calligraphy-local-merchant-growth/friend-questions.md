# 给书法朋友的 10 个问题

> 用途：用户可直接复制给朋友  
> 目标：收集足够信息，让 Agent 做一页样例包  
> 注意：先沟通，不销售，不承诺效果。

## 复制版

```text
我最近在做一个 AI 商业实验室的小实验，想先帮身边真实的小商家做获客包装。

你是做书法的，我觉得很适合试一版。
先不谈收费，也不承诺效果，我想先问你几个问题，做一页样例给你看看有没有用：

1. 你现在主要教谁？少儿、成人、亲子，还是都做？
2. 你现在主要卖什么？长期课、体验课、作品定制，还是活动？
3. 你有没有线下空间？在北京哪个区域？
4. 你现在一节课/一次体验/一个作品大概多少钱？
5. 你最想招哪类客户？
6. 你现在主要靠什么获客？熟人、朋友圈、小红书、线下，还是机构合作？
7. 你最头疼的获客问题是什么？
8. 你有没有可以展示的作品照片或课程照片？如果不方便发真人照片，作品也可以。
9. 你愿不愿意先试一条朋友圈或小红书内容？
10. 你不想做哪些方向？比如少儿、成人、企业活动、作品定制等。

我会先做一页样例，你看真实感受就行。
```

## Agent 需要的信息

用户拿到回答后，交给 Agent 生成：

- 定位
- 体验课主题
- 小红书内容
- 朋友圈内容
- 私域话术
- 499/999 报价是否成立
