## Experiment

书法朋友本地商家增长包。

## Original thesis

用户身边有一个做书法的朋友。真实关系资源可能比陌生市场更快获得反馈，因此可作为第一块试验田。

## User response

```text
还是别考虑他这个资源了，换一个吧。
```

## Revenue signal

无。

## Non-revenue signal

这是一个强信号：

```text
真实关系资源虽然高杠杆，但不等于自动优先。
```

如果用户对启用某个关系资源不舒服，继续推进会增加社会成本，并削弱项目的可持续性。

## What worked

- 快速识别了一个本地商家服务方向。
- 形成了可复用的兴趣教育/本地商家包装模板。
- 没有发生任何不可逆外部动作。

## What failed

- 对“真实资源优先”的判断过于绝对。
- 没有先评估用户是否愿意启用该关系。
- 将“可触达”误认为“适合启动”。

## Wrong assumption

```text
只要用户身边有真实资源，就应该优先使用。
```

## Better explanation

```text
真实资源是杠杆，但私人关系有隐形成本。
早期实验应优先选择：低社会压力、低承诺、可公开寻找、可复制的资源。
```

## Kernel upgrade

新增判断：

```text
资源启用舒适度 = 用户是否愿意动用该资源 + 关系压力是否低 + 不成功是否不伤关系。
```

后续机会排序不能只看“是否有资源”，还要看：

- 是否适合动用
- 是否可复制
- 是否不伤关系
- 是否能在不用该资源时继续推进
