# 强脑暴方法

> 日期：2026-06-07  
> 状态：生效草案  
> 适用范围：AI 商业实验室 / 创意发散 / 商业机会扩展

## 1. 核心判断

普通脑暴容易停在字面。

强脑暴要求从一个点跳到更远的联想，再回到商业落地。

```text
先远，再近。
先发散，再筛选。
先想象，再变现。
```

## 2. 发散路径

对任意种子，至少走十条路径：

| 路径 | 说明 |
|---|---|
| 字面 | 它直接是什么 |
| 相邻 | 和它接近的东西 |
| 相反 | 它的反面和冲突面 |
| 隐喻 | 它像什么 |
| 情绪 | 它让人感觉什么 |
| 尺度 | 从个人到城市、星球、宇宙 |
| 自然 | 天气、海洋、山川、生物 |
| 文化 | 宗教、仪式、符号、历史、艺术 |
| 技术 | 屏幕、算法、设备、接口、网络 |
| 商业 | 产品、服务、品牌、空间、活动、内容 |

## 3. 蓝色例子

```text
蓝色
→ 天空
→ 海洋
→ 绿色/红色
→ 寒冷
→ 安静
→ 忧郁
→ 自由
→ 宇宙
→ 星球
→ 科技屏幕
→ 医疗信任
→ 运动队服
→ 饮料包装
→ 冥想空间
→ 旅行目的地
```

商业落地可能变成：

- 蓝色主题冥想内容
- 海洋感咖啡馆空间改造
- 科技品牌视觉方案
- 高考后“去看海”毕业旅行内容
- 蓝色信任感医疗/教育材料设计
- 宇宙和星球主题儿童科学活动
- 自由主题青年户外社群

## 4. 和商业筛选的关系

强脑暴不是为了浪漫。

它的作用是把可能性打开，防止系统过早收敛。

之后仍然要用商业标准筛选：

```text
谁会付钱？
为什么现在？
能不能 7 天验证？
AI 能不能降低交付成本？
风险是否可控？
```

## 5. 规则

- 第一轮不急着判断。
- 必须包含远距离联想。
- 必须包含相反方向。
- 必须包含情绪和文化符号。
- 最后必须收敛到机会、素材或实验。
