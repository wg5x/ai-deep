# 生命周期市场展开方法

> 日期：2026-06-07  
> 状态：生效草案  
> 适用范围：AI 商业实验室 / 市场信号调研

## 1. 核心判断

不要只看一个事件点。

一个热点真正有商业价值，往往不是因为它本身，而是因为它带出了一条时间链和需求面。

```text
点 → 面 → 生命周期 → 机会组合 → 实验
```

## 2. 基本流程

### Step 1: 找到点

例如：

```text
高考
世界杯
春节
演唱会
政策发布
大厂产品发布
```

### Step 2: 展开时间链

```text
发生前
发生中
发生后
后续衍生
长期影响
```

### Step 3: 拆人群

```text
谁焦虑？
谁兴奋？
谁花钱？
谁收钱？
谁影响决策？
谁掌握渠道？
```

### Step 4: 拆消费与服务

```text
实体商品
本地服务
信息服务
内容服务
情绪价值
工具产品
咨询服务
线下活动
```

### Step 5: 设计实验

每个机会必须落到：

```text
目标用户：
第一服务：
第一价格：
第一渠道：
7 天验证动作：
成功/失败标准：
```

## 3. 高考例子

```text
高考
→ 考前祈福/陪考/住宿/文具/心理安抚
→ 考试日交通/餐饮/休息/防暑
→ 考后放松/聚餐/旅行/写真/数码消费
→ 出分/估分/志愿填报/专业选择/家庭决策
→ 录取/升学宴/入学装备/暑期技能
```

真正值得研究的不是“高考”两个字，而是它背后的家庭决策链、情绪周期和消费迁移。

## 4. 规则

- 不把热点当资讯搬运。
- 不只做一个时间点。
- 不做保证收益、保证录取、替代专业判断的表达。
- 高风险领域只能做信息整理、公开资料导航、决策辅助和问题清单。
- 所有商业机会都要回到真实付费验证。
