# 时政新闻监测方法

> 日期：2026-06-07  
> 状态：生效草案  
> 适用范围：AI机会雷达 / 中国本土 AI 商业闭环系统

## 1. 核心判断

时政新闻不是普通资讯。

在本项目里，时政新闻用于识别：

```text
国家阶段性重点
产业资源流向
社会关注焦点
监管和治理风向
地方场景开放
宏观风险和机会
```

它和政策法规不同：

- 政策法规是正式规则和边界。
- 时政新闻是阶段性风向和资源信号。

两者都要进入 AI机会雷达。

## 2. 为什么必须监测时政新闻

在中国市场，商业机会往往不只来自用户需求，也来自：

- 国家战略方向
- 地方产业动作
- 重大会议和活动
- 媒体叙事变化
- 重点行业被反复提及
- 政策执行落地的新闻
- 资源向某些场景集中

如果只看 AI 产品新闻，很容易错过中国本土真正会落地、会有预算、会被推动的机会。

## 3. 时政新闻分类

| 类型 | 关注点 | 商业意义 |
|---|---|---|
| 国家战略 | 新质生产力、人工智能+、制造强国、数字中国 | 判断长期风口 |
| 部委动态 | 工信、网信、发改、文旅、教育、卫健等 | 判断行业落地方向 |
| 地方新闻 | 北京/区级产业动作、场景开放 | 找本地验证入口 |
| 国际关系 | AI 治理、科技竞争、出口管制、全球合作 | 判断供应链和合规风险 |
| 社会民生 | 就业、教育、养老、医疗、消费 | 找真实需求和敏感边界 |
| 平台治理 | 内容、广告、算法、AI 标识、数据安全 | 判断平台运营风险 |
| 重大活动 | WAIC、中关村论坛、服贸会、文旅峰会等 | 找资源聚集和对外窗口 |

## 4. 处理方式

每条时政新闻要转成 `current-affairs-signal`：

```text
新闻标题：
来源：
时间：
涉及领域：
阶段性风向：
可能影响的行业：
可能出现的商业需求：
政策/合规风险：
北京本地相关性：
蓝海机会候选：
下一步验证动作：
```

## 5. 每周输出要求

每周至少输出：

- 5 条时政/宏观风向信号
- 3 条与 AI 商业机会相关的解读
- 1 条北京本地可验证机会
- 1 条风险提醒

## 6. 不做什么

不做泛泛新闻搬运。

不做政治评论。

不做敏感预测。

不做未经验证的内幕解读。

只做：

```text
公开新闻 → 商业风向 → 合规边界 → 可验证机会
```
